# Glossary

These short definitions describe how recurring terms are used **in this textbook**. They are not a complete music dictionary.

- **Amplitude** — A sample or synthesis-control magnitude. It contributes to playback level but is not identical to perceived loudness.
- **Beat** — The book's unit of symbolic musical time. Tempo converts beats to seconds for rendering or scheduling.
- **Candidate** — One proposed musical result. Passing constraints makes it valid under those rules, not aesthetically preferable.
- **Chord root / sounding bass** — The pitch class that names a chord / the lowest pitch actually voiced; inversion can make them differ.
- **Composition** — Decisions about which musical events happen and when.
- **Constraint** — An explicit, testable rule defining what is allowed. A constraint is not a judgment of quality.
- **Derived operation** — A mechanical consequence of another decision, such as converting pitch to Hz or beats to seconds.
- **Duration / onset** — How long an event lasts / where it begins. Both are measured in beats in symbolic scores.
- **Evaluation** — Description and controlled listening after generation. Metrics report features; a listener makes judgments.
- **Frequency** — Acoustic cycles per second (Hz), derived from MIDI-style pitch integers in the reference renderer.
- **Generation / selection** — Proposing alternatives / choosing among them. The same agent need not perform both.
- **Harmonic rhythm / accompaniment rhythm** — The rate of chord change / the attack pattern used to play or decorate harmony.
- **Layer / texture** — A named musical role / the combined relationship among concurrent roles.
- **Melody / motif / riff** — An ordered pitch line / a short transformable identity-bearing idea / a recurring idea that organizes groove or a section in the rock lab.
- **MIDI-style pitch** — An integer convention where 69 is A4. The book uses the numbers without requiring MIDI transport.
- **Note / `NoteEvent`** — An informal sounding pitch / the immutable record of pitch, beat onset, beat duration, and velocity.
- **Pattern / process** — A repeatable arrangement / a rule that changes material over time.
- **Performance** — Playback choices and timing that interpret a composition without changing its symbolic identity.
- **Pitch / pitch class** — A register-specific integer / octave-independent identity modulo 12.
- **Playback / sound** — Instructions mapping events to instruments and controls / the resulting acoustic signal.
- **Provenance** — Stored evidence of who or what specified, proposed, selected, transformed, derived, or revised a decision.
- **Seed** — An explicit parameter initializing a local pseudo-random generator so an experiment can be repeated.
- **Velocity** — Integer performance intensity (0–127) mapped by a chosen playback system; it is not acoustic loudness itself.
